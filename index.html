Deploy to GitHub Pages (2 Minutes)

Single-File Ready: This entire app (chatbot, offline NLP engine, 10-day itinerary, SOS matrix, budget converter, and gear checklist) lives inside one standalone index.html file — zero build steps needed!

Option A: Fastest Upload (GitHub Web UI)

  1. Save this file on your computer as index.html.
  2. Create a new GitHub repository (e.g., thailand-trip-2026).
  3. Click Add file → Upload files, drag & drop index.html, and click Commit changes.
  4. Go to Settings → Pages, set Branch to main (/root), and click Save.
  5. Your live travel app will appear at https://<username>.github.io/thailand-trip-2026/.

Option B: Git Command Line
